# Use a curated wger catalog snapshot

Seed the Exercise Catalog from a pinned, reviewed snapshot of wger rather than a live API dependency. Preserve source, author, and license metadata; ship only individually verified reusable still images with attribution; and use private Custom Exercises for gaps. This accepts a smaller and less visually consistent catalog in exchange for genuinely open, auditable, offline-capable data and avoids ExerciseDB's hosted, storage-restricted content model; see [the source comparison](../research/exercise-catalog-sources.md).
